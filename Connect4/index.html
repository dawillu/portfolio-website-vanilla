Strategize, Drop, Conquer—Every move leads to victory!
THE CLIENT
INTERACTIVE, RESPONSIVE, USER-FRIENDLY
The client-side is built with HTML, CSS, and JavaScript, offering a smooth, interactive interface where users can play the game in real-time. It communicates with the server to send and receive game moves, ensuring a responsive experience.
THE SERVER
REAL-TIME, VERSATILE, SCALABLE
The server-side is developed in C# using TCP sockets, handling the game logic and maintaining the connection between players. It processes moves, updates the game state, and sends the results back to the client, ensuring seamless gameplay.
